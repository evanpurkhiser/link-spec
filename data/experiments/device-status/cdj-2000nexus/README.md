# Genuine CDJ-2000nexus status matrix

This completed matrix uses an unmodified player-1 status payload from
Dysentery's `S05-link-browse` capture. The paired keepalive preserves the
captured model, player, CDJ class, generation, presence, model-code, and peer
count while substituting only the isolated lab address and project MAC.

The 13 declared suites contain 249 cases across ordinary extended/legacy
menus, baseline and packed-context Display Song Info, packed Play Song Info,
Delivery and every recognized no-builder sibling, and Hot Cue Bank catalog and
direct getters. Every existing player-1 declaration is reused unchanged.

All 13 variants and 249 cases were recorded from real Rekordbox 7.2.19 and
independently repeated on the isolated network. Every variant semantically
matches the corresponding derived CDJ-3000 control. Twelve variants are also
byte-exact behavior matches; Display baseline differs only in declaration-level
pagination of the same ordered 16 rows. `summary.json` binds every golden,
suite, and repeat receipt. Backend comparison is deferred.
