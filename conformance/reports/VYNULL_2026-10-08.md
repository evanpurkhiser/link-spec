# Vynull conformance against Rekordbox 7.2.19

This report records the complete safe replay catalog against Vynull on October
8, 2026. Rekordbox 7.2.19 is the behavioral oracle.

## Provenance

- Vynull commit: `2bcd104`
- Vynull source version: `2bcd104+tree.51208948b9f0`
- Vynull source tree: `51208948b9f050682f28eecbc268f2e60d21b52603758f140a7571a54f77ddc8`
- Harness source tree: `c82566f137d7f87c1cb78bf0f840fa1ba9eaa66f0dd64b418b833d43ac97cd04`
- Active suites: 287
- Explicitly deferred mutation and lifecycle suites: 149
- Oracle cases in the active catalog: 4,250

The Vynull tree includes the loopback-listener and environment-key changes
required by the adapter. Every suite ran in a fresh Vynull process so a
protocol-triggered crash could not contaminate later results.

## Results

| Measure | Result |
| --- | ---: |
| Suites completed | 281 / 287 (97.9%) |
| Cases matching exactly | 274 / 4,250 (6.45%) |
| Cases matching outcome, total, and row count | 1,001 / 4,250 (23.55%) |
| Suites matching complete behavior exactly | 0 / 287 |

Exact comparison includes typed messages, fields, rows, ordering, setup, and
transport outcomes. The coarser shape measure compares outcome, reported total,
and row count. Cases from suites with run errors remain in both denominators.

No suite matches its complete behavior because the initial setup exchange is
already different. Rekordbox replies with kind `0x0000` and values `17, 20`;
Vynull replies with kind `0x4000` and values `0, 17`. The comparison client
accepts either usable setup shape long enough to measure the remaining cases,
while retaining the setup difference in each suite result.

The strongest exact-case clusters are the smart date-format matrix (54 of 117),
smart rule matrix (19 of 39), empty-library suite (15 of 21), smart numeric
matrix (12 of 60), scalar selector drilldowns (10 of 32), and track-type family
cross (10 of 329). The track-type family cross has the largest shape match at
80 of 329 cases. These are strict protocol matches, not estimates of user-level
feature coverage.

| `smart-xml-matrix` | 73 | Vynull's dump tool rejects invalid `LogicalOperator` text |
| `adjacent-payload-fileless` | 196 | song-structure lookup dereferences a nil analysis store |
| `adjacent-payload-missing-files` | 31 | song-structure lookup dereferences a nil analysis store |
| `adjacent-payload-success` | 15 | song-structure lookup dereferences a nil analysis store |

The fractional-duration failure belongs to the adapter translation boundary.
The malformed XML failure occurs in Vynull's Rekordbox importer. The malformed
framing and payload failures are Vynull dbserver crashes observed through the
wire client.

## Reproduction

```sh
python3 conformance/replay_vynull.py --enable-vynull-replay
```

The retained local run is
`.cache/vynull-full-20261008-v4/` relative to the containing research workspace.
Its `summary.json` and `SUMMARY.md` contain every case ID, run error, exact-case
set, semantic diff path, and source hash. Generated run output is intentionally
excluded from Git.
